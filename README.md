# Nova Mart 🛒

Nova Mart is a simple and responsive e-commerce website built with React. It allows users to browse products, view product details, add products to their cart, and manage the quantity of items in the cart.

## 🚀 Live Demo

https://e-commerce-nine-iota-69.vercel.app

## ✨ Features

View product details
Add products to cart
Remove products from cart
Update cart quantity
View cart total
Login page
Responsive design

## 🛠️ Technologies Used

- React
- React Router
- Tailwind CSS
- JavaScript
- Context API
- Fetch API
- Vite

## 🔌 API

This project uses the Fake Store API to fetch product data.

https://fakestoreapi.com/products
